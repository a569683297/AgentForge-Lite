## 部署上线调研（用户提出「想把项目部署上线」）

### 实测数据（本机 Docker 实测，非估算）
- api 容器空闲 542MB；容器内单独实测：加载 embedding 后 RSS 215MB，加载 reranker 后 RSS 1534MB（bge-reranker-base = 1GB ONNX）
- db 191MB + redis 11MB + web 9MB + api（加载模型后预估 ~1.9GB）≈ 常驻 2.5-3GB（含系统）
- 磁盘：models/ 1.1GB + 镜像 + PG 数据 ≈ 需 10GB+
- 结论：2核2G 必 OOM；2核4G 及格线（余量 ~1GB）；4核8G 舒适

### 部署关键坑（已确认）
1. 本机 Apple Silicon（arm64）→ 本地构建的镜像不能在 x86 服务器跑，必须服务器上 git clone + build
2. 国内服务器拉 Docker Hub 需配加速器（腾讯云内网 mirror.ccs.tencentyun.com 等）
3. 模型 1.1GB：HF 直连不通，须 rsync 上传服务器 或 配 HF_ENDPOINT=hf-mirror.com
4. compose 端口映射当前 18000/8080 → 上线需改 80（网站默认端口）
5. .env 不在 git 里，服务器上需手动创建；Langfuse 在国内服务器上访问可能不稳（可选功能）
6. IP 直连方案：http://IP:非标端口 实践可行（云厂商主要拦 80/443 未备案），但无 HTTPS（Let's Encrypt 不给 IP 签证书）

- 备案要求：购买时长 ≥ 3 个月才支持大陆地域备案（本次走 IP 直连+8080，不涉及）
