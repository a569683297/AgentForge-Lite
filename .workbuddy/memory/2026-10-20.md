- 能拿到：content / source / page_ref / similarity / rrf_score / vector_rank / bm25_rank /

## Trace 页改为「以提问为单位」（2026-10-20 晚，已上线）

用户反馈：下拉里 N 条 `run_agent` 长得一模一样，认不出哪次是哪次提问。

**诊断（三条根因，都不是"分组错了"）**
1. 后端本来就按 traceId 分组，一次 `run_agent` = 一条 trace = 一次提问。**数据层没融合**。
2. 缺身份：下拉只有 `时刻 · run_agent · 耗时`，`run_agent` 是固定名。
3. 对话被调试运行淹没：7 天窗口 eval-judge 120 / retriever_inspect 49 / run_agent 42；
   实测某次连点检索检查器后，最近 200 span 组成的 77 条 trace **全是 retriever_inspect**。

**硬约束（实测，别再试第二次）**
- v2 `/api/public/v2/observations` 的键集里**没有 input / output / metadata** → 拿不到提问文本。
- `/api/public/v2/observations/{id}` 与 `/api/public/v2/traces/{id}` 都是 **404**（端点不存在）。
- v1 `/api/public/traces/{id}` 带 `input.user_input`，但 **2026-11-16 下线** + 一次一条 → 不可依赖。

**方案**：`messages.trace_id varchar(32)`，只在 `role='user'` 行写。
`agent_service` 两处在 root span **内部**取 `current_trace_id()`（出了 with 就是 None），
span 外传给 `append_messages`。Trace 页一次 `WHERE trace_id = ANY(...)` 批量反查。
迁移脚本 `scripts/trace_message_link_migrate.py`（含行为探针，已跑通）。

**顺带修的既有误导**：`_status_of` 旧逻辑"有 statusMessage 就算 error"，把
重排降级（level=WARNING）染成和 500 一样的红。这次实测 rerank 3006ms 超时降级
就撞上了。改成三态 ok/warning/error，`status_message` 透传到 tooltip；
`_has_error` 只认 ERROR（否则列表红点会被降级刷屏）。
⚠ 重排超时本身**没修**，只是显示对了。

**验证**：251 单测通过；真实对话 trace `7d217eef...` → messages 2359 带 trace_id、
其余三行 NULL；列表与详情都返回提问原文；kind 筛选 400/200 正常；截图见
`docs/screenshots/trace-按提问展示-2026-10-20.png`；文档 `docs/trace-按提问展示-2026-10-20.md`。

**已知限制（不是待办）**：历史对话无提问原文（永久）、单次 200 span 截断、
评测的 run_agent（persist=False）会归到 dialog 但 question=None。

## 核查：跨会话记忆（2026-10-20，只核查，未改代码）

**结论：没有跨会话记忆。这不是 bug，是范围外的能力。**

三层记忆全部锚在 `session_id`：
1. Redis 热窗口 `session:{id}:window`（8 轮 / TTL 24h）
2. PG 兜底 `messages WHERE session_id=?`（全量）
3. 会话摘要 `sessions.summary`（>20 轮后压缩已滑出窗口的部分）

`build_system_prompt(summary)` 只拼「固定人设 + **本会话**摘要」，没有任何用户级信息。
Redis 实测只有 4 个 key、全是 `session:{uuid}:window`，**零 user 级 key**。
PRD grep「跨会话 / 长期记忆 / 用户画像 / 跨对话」→ **零命中**（范围外，不是漏做）。
会话 id 在 URL（`/chat/:sessionId`），点「新对话」→ 新 uuid → 三层全空。

**实测对照（三次真实请求）**
- 会话 A：`我叫小王，请记住我的名字` → 「好的，小王，我记住了」
- 新会话 B：`我叫什么名字？` → 「我这边没有你的个人信息，所以不知道你叫什么名字」（诚实，没编）
- 回到 A：`我叫什么名字？` → 「你叫小王，你刚才告诉我的」

**要做的话（未实施，等拍板）**：独立 `user_profiles(user_key, fact_key, fact_value, ...)` 表
+ 对话后异步 LLM 抽取 + 进 system prompt。
⚠ 前置问题：项目**没有登录体系**，user_key 只能靠浏览器 localStorage 生成匿名 id →
换浏览器/设备就丢。真正的跨设备记忆需要先有账号。
