消融实验（ablation study）是什么

AgentForge-Lite · D20 评测方法论 · 名词解释卡

本文件是教学用图，口径与当天教程一致；不占教程 §1–§7 编号。

1 · 词源与一句话定义

ablation 源自拉丁语 ablatio（带走、切除）。医学上就是"切除"——心脏射频消融术，用高频电流把异常传导通路烧掉。

借到机器学习 / 系统评测里，就一句话：把系统里的某个部件拿掉，重测一遍，看性能掉多少。掉掉的那部分，就是这个部件的净贡献。

这层含义叫 归因（attribution）——把一个总效果拆到各个部件头上。

2 · 为什么非做不可

因为"我加了个组件"本身不构成证据。加了可能更好、可能没变、也可能更差。

尤其对重排：D19 实测它带来 759 ms 净成本、176.91 倍的耗时。若它只换来 0.5% 的提升，那它就是负资产，应该砍掉。不做消融，你永远不知道，只能说"感觉好像更准了"。

3 · 两种等价写法（别被名字绕晕）

写法做法叙事方向
移除式（经典消融）从最全的 C 出发逐个拿掉：C → B → A看"掉"多少
叠加式（增量）从 A 出发逐个加上：A → B → C看"涨"多少

两者的 Δ 完全一样，只是叙述方向相反。AgentForge 用的是 A / B / C 并列跑，等价于叠加式的三档。

4 · 在本项目里的具体形态

唯一变化的变量是 settings.retriever_config。

配置 向量检索 BM25 RRF 融合 bge-reranker 这一档测什么
A pure_vector ✓——— 基准线（baseline / 对照组）
B hybrid ✓✓✓— Δ(B−A) = BM25 + RRF 的净贡献
C hybrid_rerank ✓✓✓✓ Δ(C−B) = 重排的净贡献

验收口径（PRD §S2）：C 相对 A ≥ +10%。

怎么读这三个数

  • Δ(B−A) 很小甚至为负 → BM25 那一路没帮上忙（可能语料里专有名词 / 术语不够多）
  • Δ(C−B) 很小甚至为负 → 重排是负资产，那 759 ms 该省掉
  • 三个数都要报，不能只报"C 比 A 高"

6 · 三个前提，破一个实验就废

  1. 只变一个变量。同一份 50 条评测集、同一个 judge、同样的二值化规则、分母一致——唯一变的就是那三个 config。
    这正是 D19 做「检索配置化」的目的：同一份测试用例要能构建 3 个 build。若直接把重排塞进 search()，B 配置会永久消失，"重排到底有没有用"以后再也答不出来。
  2. 分母必须一致。今天探针测出的 relay-gpt 20% 失败率就是活的反例：某些配置少算几条题，分母一变，三个百分比根本不可比。
  3. Δ 必须显著大于噪声。见下一节。

7 · 消融和今天测的 ε 是什么关系（关键）

消融测的是 Δ；但 Δ 能不能信，取决于测量仪器的噪声 ε。

如果"差 4 条题"本来就是 judge 自己抖出来的，那"提升 10%"这个结论不成立。 只看 Δ 不看 ε，等于用一把刻度乱跳的尺子量长度。

而今天探针第 1 轮的教训正好是反面：连 ε 本身都会假报 0 —— 因为样本全落在 5 分或 ≤3 分， 阈值带（3.5 ~ 4.5）是空的，翻转概率必然为 0，与 judge 稳不稳无关。

所以探针第 2 轮加梯度样本 G1~G7（G3 / G4 / G5 三个 ★ 样本专门压在阈值带上）， 把样本打进 correctness ≈ 4 附近。只有这一步做完，ε 与噪声地板才是可信的。
