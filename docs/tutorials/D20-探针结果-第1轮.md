## 一、最要紧的结论：**本轮没能测到抖动，而且这不是"judge 很稳"**

两个 judge 算出来的 ε **都是 0.0000**，噪声地板 **0.00 条**。但这个数**不能用**，原因是一条硬证据：

```
judge 实际用到的分数档 = {0, 2, 3, 5}
                      ↑ 没有 1        ↑ 没有 4

二值化阈值 = correctness ≥ 4
```

**没有任何一条样本落在 4 分附近** —— 样本要么是 5（远高于阈值）、要么是 ≤3（远低于阈值）。
**阈值带（3.5 ~ 4.5）是空的** → 单次判定翻转的概率**必然为 0**，与 judge 稳不稳无关。

> 这与 D18 那次「拿 12 token 的句子测出 2.8ms」是**同一族错误**：
> **测量对象选错，得到一个看似精确、实则荒谬的数。**

**正确说法**：本轮只证明了"judge 在**易于区分**的样本上完全稳定"，**不能**推出"50 条题上差 1 条就算真差异"。
要量出真实 ε，样本必须落在**阈值带内部**。

## 二、本轮真正测出来的东西（这些是可信的）

### 1. judge 通道的工程可用性 —— 差异巨大

| 指标 | deepseek | relay-gpt (`gpt-5.6-sol`) |
|---|---|---|
| 成功率 | **70/70 = 100%** | **56/70 = 80%** |
| 失败类型 | 无 | `ReadTimeout`（已设 90s）+ **`429 Too Many Requests`** |
| 单次耗时中位 | **0.73s** | **13.76s**（≈ 19 倍） |
| 单次最慢 | 1.17s | **56.08s** |
| 70 次墙钟 | **13.2s** | **230.0s**（≈ 17 倍） |
| 整样本丢失 | 0 | **C2、C3 两个样本 5 次全失败** |

**对 D23 的含义**：消融规模约 450 次 judge 调用。
按 deepseek 的速率（并发 4）≈ 1.5 分钟；按 relay 的失败率与限流，**基本不可用** ——
不是慢，是**会有两成样本拿不到分**，而分母一变，三个配置就不可比了（Q3 同族问题）。

### 2. 分数级抖动确实存在（即使二值结论不翻转）

relay-gpt 侧出现多处**极差 = 1**，而阈值在 4，所以二值没翻转，把抖动掩盖了：

| 样本 | 现象 |
|---|---|
| B4 | `faith=[5,5,0,5,5]` —— **faithfulness 出现 0 的离群值**（同一份答案） |
| B2 / B3 / N2 | `corr` 在 0 与 1 之间摆动 |
| B1 | deepseek 判 `corr=0`，relay 判 `corr=1` —— **同一份答案、两个 judge 不同档** |

→ **只看二值翻转率是不够的，必须同时报分数级极差**（脚本已打印，但 ε 只基于二值）。

### 3. 跨 judge 一致性 12/12 = 100% —— 但这是**幸存者偏差**

被排除的恰好是 **C2、C3**（relay 全失败），而它们正是**边界样本**。
**最可能产生分歧的样本没有数据** → 这个 100% 不能当作"两个 judge 等价"的证据。
（脚本已自动标注"样本量只有 12 条，只作方向参考"。）

### 4. rubric 需要改（本轮最实用的副产品）

分数实际只用了 **0 / 2 / 3 / 5** 四档，**1 分和 4 分从未出现**。

- **4 分档空置** → 阈值带空 → 翻转率必然 0（同第一节）
- **1 分档空置** → rubric 里 `0 = 完全无关` 与 `1 = 与参考答案冲突` 的分界不清，
  "答错了但答到了点上"（B 组）被一律压到 0，**丢掉了"错得多离谱"这个区分度**
