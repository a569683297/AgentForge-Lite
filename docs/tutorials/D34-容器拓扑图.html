三条最容易搞错的规则

规则为什么
一个服务 = 一个容器 = 一台迷你电脑 4 个服务 = 4 台独立机器（各自文件系统、依赖、端口），把它们连起来的是一张公共的局域网。
容器里的 localhost 指它自己 所以 api 容器里写 localhost:5432 一定连不上 —— 那是 api 自己的 5432，门后没人。报错形态是 Connection refused（找到地址但没人应），不是 timeout。
要连谁，就写它在 compose 里的服务名 compose 把服务名注册成局域网里的域名。连数据库写 db，连缓存写 redis。
注意：api 本身也是个服务名 —— 所以写 api 指的是「api 那台机器」，而它上面没有数据库。
