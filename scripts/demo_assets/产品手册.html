1. 产品概述

AgentForge-Lite 是一套面向企业内网部署的 Agent 运行时平台，把「文档知识库 — 检索增强问答 — 工具调用型 Agent — 效果评测」四条链路收进同一个可自托管进程。

它解决的问题是：企业内部往往已经有大量制度、手册、FAQ 文档，但员工检索靠关键词翻页、问答靠人工转述。本产品将这批文档统一入库、切分、向量化，使员工可以用自然语言提问并获得带出处引用的回答；回答无法覆盖的问题，可由 Agent 调用外部系统工具继续求解。

1.1 核心能力

  • 文档知识库：支持 PDF / DOCX / Markdown / TXT 四种格式入库，自动解析、切分与向量化。
  • 混合检索问答：向量检索与关键词检索双路并行，融合后可选重排，回答附带原文引用与页码定位。
  • 工具调用 Agent：基于状态图的推理—行动循环，可装载本地工具与外部 MCP 协议工具。
  • 会话与记忆：多会话管理，长对话自动摘要压缩，避免上下文溢出。
  • 评测与可观测：内置评测集与自动评分，全链路埋点可回流至链路追踪平台。

1.2 部署形态

产品以 Docker Compose 形式交付，一条命令拉起 数据库 / 缓存 / 应用服务 / 前端站点 四个容器，无需外部托管依赖即可离线运行；大模型与嵌入模型均可指向本地推理服务。

3. 文档与知识库规格

3.1 支持的文件格式

扩展名类型解析行为
.pdfPDF 文档按页解析，每页保留页码引用；扫描件（无文本层）无法提取会明确报错
.docxWord 文档按段落解析，页码引用为空
.mdMarkdown整篇作为一段解析，页码引用为空
.txt纯文本整篇作为一段解析，页码引用为空

单文件大小上限为 20 MB。超出上限或格式不在白名单内的文件，在请求阶段即被拒绝，不会产生无效记录。

3.2 切分规格

  • 切片长度：300 字符（每片的目标字符数）
  • 相邻重叠：50 字符（防止把一句话从中间切断）
  • 切片步长 = 切片长度 − 重叠 = 250 字符

3.3 入库流程

上传接口返回 202 Accepted（已受理）而非 200，随后在后台完成解析、切分与向量化。文档状态依次为 processing → ready（成功）或 failed（解析失败，如损坏的 PDF）。调用方可轮询文档列表接口跟踪状态。

4. 检索与问答规格

4.1 两路召回

检索路径原理适用场景
向量检索查询与切片分别编码为向量，按余弦相似度排序（pgvector）语义相近、用词不同
关键词检索基于 PostgreSQL 全文索引（tsvector + GIN）打分专有名词、编号、缩写

4.2 融合与重排

  • 融合方式：RRF（倒数排名融合），融合常数 k = 60，两路各取前 20 条候选。
  • 重排（可选）：使用交叉编码器模型对候选逐一打分后重新排序，精度更高但耗时更长。
  • 返回条数：默认 top_k = 5。

4.3 三种检索模式

模式链路
pure_vector仅向量检索
hybrid向量 + 关键词，RRF 融合
hybrid_rerank（默认）向量 + 关键词 → RRF 融合 → 交叉编码器重排

4.4 模型规格

用途模型规格
词嵌入（向量化）BAAI/bge-small-zh-v1.5中文，512 维，本地 ONNX 推理
重排BAAI/bge-reranker-base交叉编码器，本地 ONNX 推理，超时 3 秒
对话生成可配置（云端 API 或本地服务）与嵌入模型解耦配置
注意：向量维度与嵌入模型强绑定。更换嵌入模型时必须重建全部索引，否则相似度计算将失去意义。

5. Agent 与工具规格

5.1 推理—行动循环

Agent 基于状态图编排，单轮问答的循环为：生成回答 → 若需要外部信息则发起工具调用 → 执行工具 → 带着结果再次生成。循环设有最大轮次上限，超限后返回当前可得的最佳回答，不会无限重试。

5.2 工具来源

来源说明
内置工具随产品发布，如时间查询、知识库检索
外部 MCP 工具经协议客户端动态挂载，工具名带来源前缀以区分同名冲突

5.3 降级策略

外部工具服务不可达时不会阻断主流程：连接失败的来源整体下线，Agent 自动降级为纯知识库问答。可通过工具列表接口确认当前已装载的工具及其来源。

6. 接口规格

接口方法用途

/api/documentsPOST / GET上传文档 / 文档列表
/api/documents/{id}/previewGET文档详情与切片预览
/api/documents/{id}DELETE删除文档（级联删除切片）
/api/sessionsGET会话列表与消息明细

所有接口统一挂在 /api 前缀下。生产部署时由前置 Web 服务同源转发，前端站点与接口服务无需跨域配置。
